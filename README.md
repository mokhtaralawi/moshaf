## 🌟 نبذة عن المشروع

**« زاد الأنصاري »** هو تطبيق إسلامي نوعي صُمم خصيصاً لحلقات ومجموعات قراءة القرآن الكريم ومدارسته (« مشورة إب »)، بهدف تيسير متابعة الورد القرآني، تكاليف الأذكار النبوية، والأنشطة الإيمانية اليومية.

يتميز التطبيق بتجربة مستخدم فاخرة مستوحاة من الهوية الإسلامية الزمردية (`Emerald & Gold Luxury Theme`) مع دعم العمل بدون إنترنت كلياً، ومزامنة البيانات تلقائياً فور عودة الاتصال.

---

## ✨ المميزات الرئيسية

### 1. 🔐 نظام المصادقة والصلاحيات المتقدم (RBAC)

- **واجهة دخول موحدة:** تسجيل دخول لجميع المستخدمين والمدراء مع توجيه ذكي حسب الدور:
  - **المدير (`Admin`):** يُوجّه للوحة التحكم الإدارية الشاملة مع إمكانية إضافة مدراء مساعدين.
  - **القارئ (`User`):** يُوجّه لشاشة الورد اليومي والمهام الشخصية.
- **جلسة مستمرة وآمنة:** تسجيل الدخول لمرة واحدة مع حفظ الجلسة محلياً ليعمل التطبيق بدون اتصال.
- **نافذة التهيئة لأول تسجيل (`First-Login Onboarding`):** نافذة ترحيب وتأمين فورية تتيح للأعضاء تعيين كلمة مرور شخصية خاصة بهم أو المتابعة بمرونة.

### 2. 📖 محرك إدارة الورد القرآني

- **توزيع الورد التلقائي:** توزيع 30 جزءاً على القراء وتحديد نطاق الصفحات والسور تلقائياً.
- **الورد متعدد الأجزاء:** إمكانية تحديد مقدار الورد اليومي (جزء واحد، جزأين، 3، أو أكثر).
- **متابعة الختمة:** شريط تقدم لكل قارئ يوضح نسبة إنجازه في الختمة الحالية.
- **ترحيل يومي بضغطة زر:** ترحيل جميع القراء إلى ورد اليوم التالي وحفظ الأرشيف.

### 3. ⭐ محرك التكاليف والأنشطة الديناميكية

- لا يقتصر النظام على الورد فقط، بل يسمح للمدير بإضافة تكاليف مخصصة:
  - **تكاليف الأذكار والعبادات:** أذكار الصباح والمساء، الاستغفار 100 مرة، الصلاة على النبي ﷺ.
  - **أنشطة ومهام عامة:** صيام النوافل، صلاة الضحى، قيام الليل، وأي تكليف يحدده المدير.
- خيارات التفاعل لكل قارئ: **(أديتها ✅ / اعتذر ✋)** مع حفظ سجل الإنجاز.

### 4. 📴 العمل بدون اتصال ومزامنة ذكية (Offline-First)

- التطبيق يعمل بنسبة 100% في غياب شبكة الإنترنت عبر التخزين المحلي فائق السرعة (`AsyncStorage`).
- طابور أحداث ذكي (`Action Queue`) يخزن جميع التعديلات ويرفعها تلقائياً عند استعادة الاتصال.
- شارة حالة اتصال لحظية في الواجهة توضح للمستخدم حالة المزامنة.

### 5. 🕌 رسالة التهنئة والتحفيز التفاعلية

- عند إتمام القارئ لورده اليومي، تظهر له نافذة احتفالية إسلامية راقية بالرسالة التحفيزية:
  > *"هنيئاً لك يا قارئ القرآن، أنت من أهل الله وخاصته"*
  >
- يمكن للمدير تخصيص وتعديل هذه الرسالة في أي وقت من لوحة التحكم.

### 6. 📊 الاستبيانات والتقارير وتصدير PDF

- إمكانية إنشاء استبيانات سريعة بنعم / لا وتوجيهها لجميع الأعضاء.
- طباعة وتصدير تقارير الإنجاز والاستبيانات بملفات **PDF** احترافية تدعم التاريخين الهجري والميلادي.

## 🚀 التشغيل والتطوير المحلي

### المتطلبات الأساسية

- تثبيت [Node.js](https://nodejs.org/) إصدار 20 LTS أو أحدث.
- تثبيت حزمة Expo CLI.

### خطوات التشغيل

1. استنساخ المستودع وتثبيت الحزم:

   ```bash
   git clone https://github.com/mokhtaralawi/moshaf.git
   cd moshaf
   npm install --legacy-peer-deps
   ```
2. تشغيل التطبيق في بيئة التطوير:

   ```bash
   # تشغيل خادم Expo
   npx expo start

   # أو فتح نسخة الويب مباشرة في المتصفح
   npm run web
   ```

## 📱 بناء نسخة الهاتف (Android APK)

### الخيار 1: البناء السريع عبر سحابة Expo (EAS Build) - موصى به

```bash
# 1. تثبيت أداة EAS وتنسيق الدخول
npx eas-cli login

# 2. بناء ملف APK جاهز للتثبيت
npx eas-cli build --platform android --profile preview
```

> سيمنحك رابطاً مباشراً ورمز QR لتحميل وتثبيت ملف الـ APK فوراً على هاتفك.

### الخيار 2: البناء المحلي عبر Gradle (بدون إنترنت)

إذا كان خادمك أو جهازك يحتوي على Android SDK و Java 17:

```bash
# توليد ملفات المشروع الأصيل
npx expo prebuild --platform android

# بناء ملف APK للإنتاج
cd android
./gradlew assembleRelease
```

> يخرج الملف النهائي في المسار:
> `android/app/build/outputs/apk/release/app-release.apk`

## 🌐 النشر على استضافات وسيرفرات لينكس (Linux Hosting)

المشروع مجهز بالكامل بأفضل ممارسات الإنتاج عبر:

- **Node.js + PM2 + NGINX** (لأعلى أداء واستقرار).
- **Docker & Docker Compose** (للتشغيل بأمر واحد: `docker compose up -d`).
- **cPanel / Apache** (رفع مجلد `dist/` مع ملف `.htaccess` المرفق).

للاطلاع على الخطوات التفصيلية للنشر على سيرفر لينكس خطوة بخطوة، راجع الدليل المخصص:
👉 **[`DEPLOYMENT_LINUX.md`](./DEPLOYMENT_LINUX.md)**
